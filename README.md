# go-pusher-tailwind-chat-app
## Small app using:
* Go
* Tailwind
* Pusher

## install project:

> make sure you have Go installed.

Clone repo and set the following environment variables before running the server:

```
export PUSHER_APP_ID=<your-app-id>
export PUSHER_KEY=<your-key>
export PUSHER_SECRET=<your-secret>
export PUSHER_CLUSTER=<your-cluster>
```

Run `go run chat.go` to start the application.
